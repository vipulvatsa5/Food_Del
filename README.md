### 🍔 Food_Del – Full Stack Food Delivery Web App

Food_Del is a full-stack food delivery web application built using the MERN stack. It allows users to browse food items, add them to cart, authenticate, and place orders. This project demonstrates real-world full-stack development and deployment.

Live Demo : https://food-del-gyoc.vercel.app/

Features

✅ User Authentication (Login / Signup)
✅ Browse Food Items
✅ Add to Cart
✅ Remove from Cart
✅ Cart Total Calculation
✅ Persistent Cart (Saved in Database)
✅ Order Placement
✅ Responsive UI
✅ Backend API Integration
✅ Fully deployed (Frontend + Backend)

### Installation and Setup
1️⃣ Clone Repository
git clone https://github.com/vipulvatsa5/Food_Del.git
cd Food_Del

2️⃣ Backend Setup
cd backend
npm install
npm run server

Create .env file:

PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret

3️⃣ Frontend Setup
cd frontend
npm install
npm run dev

Create .env file:

VITE_API_URL=http://localhost:5000
### 🔑 Environment Variables
### Frontend (.env)
VITE_API_URL=your_backend_url

### Backend (.env)
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
